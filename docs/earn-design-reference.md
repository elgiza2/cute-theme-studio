# Earn design reference

The official shadcn/ui dashboard example presents a restrained information hierarchy: a clear page heading, a small set of summary cards, generous spacing, and responsive primitives that can be customized. Source: https://ui.shadcn.com/examples/dashboard

The project already includes shadcn-style primitives such as Button, Dialog, Progress, Tabs, and GlassSheet. The new Earn page should use the existing tokens and primitives rather than introducing a generic dashboard system. The visual direction is intentionally quieter: one primary balance surface, one invite action, a compact reward list, and a lightweight activity list. No decorative icon grid or emoji should be used.
